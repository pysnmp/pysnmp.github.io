pysnmp

SNMP for Python

Four projects, one stack: an SNMP engine, the MIB compiler it resolves modules with, the ASN.1 codec underneath both, and the MIB corpus they read. All pure Python, BSD licensed, and maintained together.

The projects

Each sits on the one below it. Install the top and you have the rest; use any of them on its own if that is all you need.

pysnmp

SNMP v1, v2c and v3 for Python

A complete SNMPv1/v2c/v3 engine: command generator and responder, notification originator and receiver, USM authentication and privacy, VACM access control, and an asyncio API. The MIB layer resolves symbolic names through pysmi.

  • SNMPv1, v2c and v3 in one engine
  • USM with SHA-2 authentication and AES-192/256 privacy
  • View-based access control (RFC 3415)
  • asyncio transport and API

pysmi

SMI MIB parser and compiler

Turns ASN.1 MIBs into pysnmp modules, JSON documents or a corpus database. Understands SMIv1, SMIv2 and the de-facto dialects, and pulls missing modules from directories, ZIP archives or HTTP. pysnmp calls it behind the scenes; mibdump, mibcopy and mibcorpus expose it directly.

  • SMIv1, SMIv2 and de-facto dialects
  • Emits pysnmp modules, JSON and SQLite corpora
  • mibdump, mibcopy and mibcorpus command-line tools
  • 210 standard modules bundled

pyasn1

ASN.1 types and codecs

Generic ASN.1 types (X.208) with standards-compliant BER, CER and DER codecs. Written for SNMP, general enough for anything built on ASN.1, and able to work over streams of serialised data rather than whole buffers.

  • ASN.1 types to X.208
  • BER, CER and DER codecs
  • Decodes from streams, not just buffers
  • No dependencies, thread-safe

mibs

5,500 MIB modules, served over HTTP

The MIB collection the rest of the stack resolves against: standard modules plus roughly 285 vendor trees, built reproducibly by pysmi's mibcorpus and published as ASN.1 sources, JSON documents, an OID index and a corpus database. Also shipped as OCI images and a Helm chart.

  • 5,510 modules, 767,870 nodes
  • ASN.1 sources, JSON documents and an OID index
  • core.db: the SMI model as SQLite, queried by OID
  • mibserver Helm chart and scratch-based OCI images

https://pysnmp.github.io/mibs/asn1/@mib@

The MIB corpus over HTTP

The corpus is the one part of the stack you consume over the wire rather than install. These paths are stable; point a compiler or a MIB browser straight at them.

PathWhat it serves
asn1/<MODULE> The MIB source, under its bare module name.
json/<MODULE>.json The same module as data: names, OIDs, syntax, access, status.
index-v2.csv OID to module, one row per anchor. Supersedes index.csv.
standard.txt The names of the standard modules in the corpus.

Get started

Installing the engine brings the compiler and the codec with it. Point it at the corpus and it resolves any module in there on demand.

uv add pysnmplib

import asyncio

from pysnmp.hlapi.asyncio import *


async def run():
    snmpEngine = SnmpEngine()

    errorIndication, errorStatus, errorIndex, varBinds = await getCmd(
        snmpEngine,
        CommunityData("public", mpModel=1),
        UdpTransportTarget(("localhost", 161)),
        ContextData(),
        # Resolved through pysmi, against the MIB corpus.
        ObjectType(ObjectIdentity("SNMPv2-MIB", "sysDescr", 0)),
    )

    if errorIndication:
        print(errorIndication)
    else:
        for varBind in varBinds:
            print(" = ".join(x.prettyPrint() for x in varBind))

    snmpEngine.transportDispatcher.closeDispatcher()


asyncio.run(run())
